## AI Assistant Guidelines

When working on this repository, AI assistants should:

1. **Read before modifying**: Always read and understand existing code before making changes
2. **Follow existing patterns**: Match the style and conventions already in use
3. **Keep changes focused**: Make minimal, targeted changes that address the specific request
4. **Avoid over-engineering**: Don't add unnecessary abstractions or features
5. **Update documentation**: Keep CLAUDE.md and other docs in sync with code changes
6. **Test changes**: Run relevant tests and verify functionality
7. **Commit appropriately**: Use clear commit messages and atomic commits

### Things to Avoid

- Creating unnecessary files or documentation
- Adding features beyond what was requested
- Making assumptions about unread code
- Introducing security vulnerabilities (XSS, SQL injection, etc.)
- Breaking existing functionality
