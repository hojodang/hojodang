## 5. 비즈니스 모델 캔버스

### 5.1 핵심 가치 제안
> "태어나기 전 부모님의 가장 행복한 순간에 함께하는 경험"

- 감성적 가치: 시간을 초월한 가족 연결
- 기능적 가치: 간편한 사진 업로드 → 고품질 결과물
- 사회적 가치: SNS 공유, 가족 선물

### 5.2 타겟 고객

| 세그먼트 | 특징 | 구매 동기 |
|----------|------|----------|
| **2030 자녀** | 부모님 선물 목적 | 어버이날, 결혼기념일 |
| **신혼부부** | 부모님께 감사 선물 | 결혼 후 첫 어버이날 |
| **중년층** | 부모님 추억 | 돌아가신 부모님 |

### 5.3 수익원 다각화

```
1차 수익: 이미지 생성 (핵심)
├── 건별 결제
└── 크레딧 패키지

2차 수익: 프리미엄 서비스
├── 동영상 생성
├── 고해상도 업스케일
└── 추가 장면 생성

3차 수익: 실물 상품
├── 인화 서비스
├── 액자/포토북
└── 캘린더/굿즈

4차 수익: B2B
├── 사진관/스튜디오 API
├── 웨딩업체 제휴
└── 플랫폼 라이선싱
```

### 5.4 채널 전략

| 채널 | 용도 | 우선순위 |
|------|------|----------|
| 인스타그램/틱톡 | 바이럴 마케팅 | ⭐⭐⭐ |
| 네이버 블로그 | SEO/후기 | ⭐⭐⭐ |
